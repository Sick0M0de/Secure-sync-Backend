# SecureSync Backend

A modular, production-ready Task Management REST API built with **FastAPI**, backed by **PostgreSQL**, secured with **JWT Authentication**, and containerized using **Docker**.

## Tech Stack
* **Framework:** FastAPI
* **Database:** PostgreSQL (SQLAlchemy ORM)
* **Authentication:** OAuth2 with Password hashing & JWT Tokens
* **Package Management:** `uv`
* **Containerization:** Docker & Docker Compose
